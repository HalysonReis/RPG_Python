Este é um jogo Rpg de terminal

Meu propósito com esse jogo é melhorar os meus conceitos de programação e me divertir.

O que vai ter no jogo
- combate com monstros
- venda e compra de itens 
- uma IA para gerar hitórias ou eventos (vou ver ainda)
- cores, "animações" no terminal, e outras coisas

o que o jogador vai poder fazer
- aumentar de nivel, o que influencia na vida, força e resiliência (aguentar ataques)
- equipar itens como: armaduras, escudo e espadas
- usar itens para recuparar vida
- comprar itens novos na loja
- caçar monstros e explorar

Em cada turno geral o jogador vai poder explorar novos lugares, ver o inventário, visitar logista e usar itens.
Durante o combate tem quatro opições: 1 - atacar, 2 - defeder, 3 - fugir, 4 - usar poção

para lutas tem quatro lugares: as planices, borda de floresta, floresta profunda e montanha do dragão
